# 🎰 Slot Machine Game (Python)

A simple **Slot Machine Game** built using Python.
The project simulates a real slot machine where players place bets, spin random symbols, and win rewards based on matching symbols.

## 🚀 Features

* 💰 Starting balance system
* 🎲 Random symbol generation using Python's `random` module
* 💵 User bet validation
* 🎰 Three-symbol slot spin
* 🏆 Reward system based on matching symbols
* 📉 Balance update after every round
* 🛑 Game over condition when balance reaches zero

## 🛠️ Technologies Used

* Python 3
* Random Module

## 🎮 How It Works

1. Player starts with a fixed balance.
2. Player enters a bet amount.
3. The slot machine generates 3 random symbols.
4. If all three symbols match:

   * Player wins a reward based on the symbol.
5. If symbols do not match:

   * Player loses the bet amount.
6. The game continues until the balance becomes zero.

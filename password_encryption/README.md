# 🔐 Encryption Tool (Caesar Cipher)

A simple command-line **Encryption & Decryption Tool** built with Python using the **Caesar Cipher** algorithm. This project encrypts and decrypts lowercase text messages by shifting each letter based on a user-provided key.

## 🚀 Features

* Encrypt lowercase text messages
* Decrypt encrypted messages
* User-defined encryption key
* Preserves spaces in messages
* Menu-driven interface
* Uses Python's `ord()` and `chr()` functions

## 🛠️ Technologies Used

* Python 3

## 📚 Concepts Practiced

* `while` loops
* `if-elif-else` statements
* `for` loops
* String manipulation
* ASCII conversion (`ord()` & `chr()`)
* Modulo operator (`%`)
* User input handling

## ▶️ How to Run

1. Clone the repository.
2. Open the project folder.
3. Run the program:

```bash
python encryption.py
```


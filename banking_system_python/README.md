# Banking System Project

A console-based Banking System built using Python.

## Features

- Create Account
- Deposit Money
- Withdraw Money
- Check Balance
- View All Accounts
- Exit System

## Concepts Used

- Python Lists
- Dictionaries
- Loops
- Conditional Statements
- User Input Handling
- Data Searching and Updating

## How to Run

1. Clone the repository
2. Run:

python banking_system.py
